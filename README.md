# The Second Time Is a Bug: companion code

Companion repository for the book *The Second Time Is a Bug: A field workbook for
engineering with AI coding agents*. Everything the book shows runs here:

- **Invoicer** (`app/`), a small invoicing app for freelancers, the running example.
- **billing-export** (`legacy/`), a deliberately tangled 2014 exporter for the legacy chapter.
- **Guards** (`guards/`), one small script per guard the book builds, and the gate that runs them.
- **Drills** (`drills/`), one per agent mistake. Each makes the mistake in a scratch
  copy and shows the guard catching it. No API key, no model, no network.
- **A toy agent** (`toy-agent/`), an agent loop of two dozen lines driven by a scripted fake model.
- **Templates** (`templates/`) to copy into your own repository, and an **experiment kit**
  (`experiment/`) for measuring whether the harness pays.

TypeScript on Node, with zero runtime dependencies and no build step.

The code the book quotes, and the messages the guards and drills
print, are kept within 64 columns, the width of the book's printed
page. Guard output wraps with a hanging indent
(`guards/lib/wrap.ts`).

## Requirements

- Node.js 22.18 or later. Node runs the `.ts` files directly (type stripping is on by
  default from 22.18). Check with `node --version`.
- git (the drills make throwaway git repositories in your temp folder).
- For the two browser drills (D13, D14) and `npm run e2e`: Chromium for Playwright,
  installed once with `npx playwright install chromium`.

## Quickstart

```sh
npm install            # dev tools only: typescript, @types/node, @playwright/test, axe-core
npm test               # unit tests and the legacy golden master
npm run typecheck      # tsc --noEmit
npm run gate           # every guard, fast ones first; refuses on any failure
npm run drill D06      # one drill: the float-money guard catches a parseFloat
npx playwright install chromium   # once, for drills D13 and D14
npm run drills         # all 26 drills and a summary table (a few minutes)
npm run e2e            # browser and accessibility tests
npm start -- --seed-demo   # Invoicer on http://127.0.0.1:3000 with a demo client
```

Without Playwright's Chromium, `npm run drills` does not run D13 and D14. It says
so and ends with exit code 1, because the run is not complete:

    24 of 26 drills behaved as expected; 2 need Chromium (npx playwright install chromium).

Install Chromium and run it again. The runner's own tests, which are not part of
`npm test`: `node --test drills/test/*.test.ts`.

`npm run gate` compares your working tree with `HEAD`. Outside a git repository the
diff-based guards report "skipped" rather than guessing. In CI, set
`GUARD_BASE=origin/main` to check a whole branch, as `.github/workflows/gate.yml` does.

## How the guards report

Every guard prints `name: ok (...)` or `name: FAILED` followed by one entry per problem:
where it is, what is wrong, and what to do next. They are written to be read by an
agent as much as by a person. Exit code 0 means pass, 1 means fail;
`destructive-command.ts` uses 2 to block, the usual convention for agent hooks. Each
time a guard fires it appends a line to `.harness/guard-log.jsonl`, which
`guards/guard-audit.ts` reads to find guards ready to retire.

## Network

Nothing here needs the network after `npm install`, except the optional
`node guards/package-check.ts --online`, which asks registry.npmjs.org.
